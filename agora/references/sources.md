# Using the learner's own materials

Use this when the learner shares PDFs, notes, slides, a syllabus, past exams or links. Their course defines what "correct" means for them, so their materials come first.

## 1. Intake
Register every material in the notebook's `sources.md` with a short id (S1, S2…):
```
# ÁGORA — Sources
| id | title | type | author / course | language | location | coverage (chapters → weeks) | quality notes |
|---|---|---|---|---|---|---|---|
## Glossary (when sources are in a language other than the learner's)
## Held-out set (past exams or graded tests: not used before W12)
```

## 2. Reading efficiently
- For long files, read the table of contents and introduction first, then only the chapter needed for the current week. Note page or section numbers as you go.
- If a file is scanned or unreadable, say so and ask for a text version or another copy. Never pretend to have read what you could not open.
- Large collections: map them first (which file covers what), then go deep one topic at a time.

## 3. Mapping to the plan
- Map syllabus blocks to weeks W1–W10 in `profile.md`.
- Mark **gaps**: parts of the learner's goal that their materials do not cover. Suggest a source to fill each gap using the quality criteria in `topic-cycle.md`, and say whether you verified it exists.

## 4. Cards from sources
- Write cards in your own words; one idea per card; prefer why / when-does-it-fail / apply.
- Fill the `source` column with id and location: `S1 p.45`, `S2 §3.2`, `S3 slide 12`.
- Do not copy long passages. Short quotes only when the exact wording matters (definitions, legal text).

## 5. Problems from sources
- Prefer the source's own exercises: hide the solutions, let the learner attempt first, and use the source's solution only for correction.
- Build **isomorphic variants** (same structure, new numbers or context) for practice and transfer; label them `variant of S1 ex. 4.7`.
- **Held-out set:** past exams are kept for the final transfer test. Do not show or paraphrase them earlier.

## 6. Fidelity
- Grade against the learner's source: its notation, conventions and definitions.
- If your knowledge disagrees with the source, say so explicitly, explain both versions and why, and suggest checking with the teacher. Never override the source silently.
- In feedback, point to where to look: "see S1 p.45".

## 7. Language
- If a source is in a language other than the learner's, explain in the learner's language and keep a glossary of key terms (source term → learner's term) in `sources.md`.
- When the anchor subject is a language, authentic sources in the target language are the core material; graded difficulty matters more than authenticity at Foundations level.

## 8. Privacy and copyright
- The learner's materials stay in their notebook. Do not publish or redistribute them.
- Generated outputs (manual, card decks, summaries) must not reproduce substantial portions of the sources.
