# Example: a 30-minute session in attention mode (English)

> Illustrative and fictional. Attention mode is opt-in; it changes the packaging (short blocks, one visible task, movement breaks, fewer cards), not the method.
> Also available in [Español](session-attention-mode.es.md).

**Context:** self-taught learner · anchor subject: Python · Intermediate · week 4 · attention mode on (12-minute blocks, best focus window: mornings).

---

**Learner:** Ágora, 30 minutes. I've been off for three days.

**Ágora:** Welcome back — that's a comeback, and it counts. Sleep and energy (1–5)?

**Learner:** 7 hours, energy 3.

**Ágora:** Energy 3 → 30-minute format, two blocks. **Start ritual (2 min):** phone in another room, open only `exercises_week4.py`, write your first tiny action and one if-then plan.

**Learner:** First action: open exercise 2. If I want to check Discord, I'll write it on the parking list.

**Ágora:** **Block 1 — 12 min (now: retrieve).** Only 4 cards today. Answer without looking, then tell me your predicted score.
1. What makes a recursive function stop?
2. What does `dict.get(key, default)` return if the key is missing?
3. Why is `[[]] * 3` a trap?
4. Trace `f(3)` for `def f(n): return 1 if n == 0 else n * f(n-1)`.

**Learner:** *(answers)* Maybe 3 out of 4.

**Ágora:** 4/4 — 100 %, you underestimated yourself by 25 points. Now one chunk of study: *list comprehensions with a condition*. Worked example first; after each line, tell me in a few words why it's there. 8 minutes left in this block.

*(…the learner self-explains the example…)*

**Ágora:** Block 1 done. **Movement break, 3 min** — stand up, walk, water. Anything for the parking list?

**Learner:** "Reply to Ana" — parked.

**Ágora:** **Block 2 — 10 min (now: solve, problem 1 of 1).** Rewrite this loop as a comprehension that keeps only even squares. 7 minutes, then explain it aloud.

**Learner:** `[x*x for x in nums if x % 2 == 0]` … and I explain: the filter runs before the expression, so only even numbers get squared.

**Ágora:** Correct, no hints (L2, H0). Follow-up: what changes if you want squares that are even, rather than squares of even numbers? *(…the learner answers…)* Good. 3 minutes left: **correct + log.**

**Log:** recall 4/4 with prediction 75 · one valid L2 · explanation 3/4 · a comeback after 3 days off · 3 new cards (the review queue stays capped at 8).
**Close:** next session tomorrow morning, same block length. First task already written for you: "open exercise 3".
